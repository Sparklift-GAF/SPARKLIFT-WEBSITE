# Sparklift Global Academy Foundation — Website

## Run locally
1) Install Node.js (LTS)
2) Open terminal in this folder

npm install
npm run dev

## Add your logo
Put your logo in: public/logo.png
Then in src/App.jsx set: const LOGO_URL = "/logo.png";

## Deploy FREE (Vercel)
1) Upload this folder to GitHub
2) Vercel.com → New Project → Import repo → Deploy
